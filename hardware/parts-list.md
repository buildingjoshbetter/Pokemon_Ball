# Parts List

Everything you need to build the PokeBall OpenClaw rig.

## Electronics

| Part | Qty | Price | Notes |
|------|-----|-------|-------|
| Raspberry Pi 5 (8GB) | 1 | ~$80 | Pi 4 (4GB+) also works |
| USB-C power supply (5V 5A) | 1 | ~$12 | Use the official Pi power supply |
| MicroSD card (32GB+, A2 rated) | 1 | ~$10 | Or boot from USB SSD |
| 5mm LED - Red | 1 | ~$0.10 | Standard through-hole |
| 5mm LED - Green | 1 | ~$0.10 | Standard through-hole |
| 5mm LED - Blue | 1 | ~$0.10 | Standard through-hole |
| 330Ω resistor | 3 | ~$0.10 | 220Ω-470Ω all work |
| Jumper wires (F-F) | 4 | ~$0.50 | Female-to-female for GPIO header |
| Small heatsink | 1 | ~$3 | Optional but recommended |

## 3D Printing

| Part | Material | Notes |
|------|----------|-------|
| PLA filament - Red | ~30g | Top half |
| PLA filament - White | ~37g | Bottom half + button |
| PLA filament - Black | ~18g | Center band + button bezel |

## Tools

- Soldering iron (or breadboard for prototyping)
- Hot glue gun (for mounting Pi inside shell)
- Drill with small bit (for USB-C cable hole)
- Wire strippers

## Total Cost

| Category | Cost |
|----------|------|
| Raspberry Pi 5 + power + SD | ~$102 |
| LEDs + resistors + wires | ~$1 |
| 3D print filament | ~$2 |
| **Total** | **~$105** |

If you already have a Pi, total additional cost is under $5.
